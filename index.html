How to Edit Questions

Questions are defined at the very top of the script tag in this index.html file.

// Open index.html and locate:
const QUIZ_DATA = [ ... ];

Structure format for each question:

{
  id: 1,
  question: "Your custom question here?",
  options: ["Option A", "Option B", "Option C", "Option D"],
  answer: 2, // 0 = Option A, 1 = Option B, 2 = Option C, etc.
  explanation: "Optional explanation displayed after selecting an answer."
}

Once modified, commit your changes back to GitHub and your host will automatically publish the new version!
