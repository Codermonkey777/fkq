How to Edit or Add Questions

All your questions live right inside this file! You don't need a database or back-end server.

// 1. Open index.html in any text editor or VSCode
// 2. Scroll to the bottom and locate:
const QUIZ_DATA = [ ... ];

Each question object follows this simple structure: 

{
  id: 1,
  question: "Your custom question text goes here?",
  options: ["Option A", "Option B", "Option C", "Option D"],
  answer: 2 // Index of correct option (0 = Option A, 1 = Option B, etc.)
}

Simply edit the strings, save the file, commit your changes back to GitHub, and Vercel will auto-update your live web link in seconds!
